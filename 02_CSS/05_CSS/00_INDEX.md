## **8. Text Align Property**

### **Explanation:**
The `text-align` property in CSS is used to control the horizontal alignment of text within an element. It affects the inline content inside the container and determines how text flows within the available space.

### **Common Values:**
- **`left`**: Aligns the text to the left edge of the container. This is the default value for most languages.
- **`center`**: Centers the text horizontally within the container.
- **`right`**: Aligns the text to the right edge of the container.
- **`justify`**: Stretches the text so that both the left and right edges are aligned, with spaces adjusted between words.
