### **1. Font Weight**

#### **What is Font Weight?**
- The `font-weight` property adjusts the thickness of text. It controls how bold or light the text appears on the screen.

#### **Why Use Font Weight?**
- To emphasize or de-emphasize specific sections of text.
- To enhance readability and visual hierarchy.

#### **Syntax and Values**
```css
font-weight: value;
```

##### Common Values:
- **normal**: Standard weight (default).
- **bold**: Bold text.
- **lighter**: Lighter than the parent element's weight.
- **bolder**: Bolder than the parent element's weight.
- Numeric values (100 to 900): Specifies the weight more precisely (e.g., `font-weight: 400` for normal weight).


### **2. Text Decoration**

#### **What is Text Decoration?**
- The `text-decoration` property is used to style the text with decorations like underlines, overlines, or line-through effects.

#### **Why Use Text Decoration?**
- To indicate hyperlinks or changes in content (e.g., strikethrough for completed tasks).
- To enhance text presentation in web design.

#### **Syntax and Values**
```css
text-decoration: value;
```

##### Common Values:
- **none**: Removes decoration.
- **underline**: Adds an underline.
- **overline**: Adds a line above the text.
- **line-through**: Adds a strikethrough line.
