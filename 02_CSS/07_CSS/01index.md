### **1. Line Height**

#### **What is Line Height?**
- The `line-height` property defines the vertical spacing between lines of text. It is crucial for enhancing readability, especially for large blocks of text.

#### **Why Use Line Height?**
- To avoid overcrowded or overly spaced lines.
- To make text easier to read and visually appealing.

#### **Syntax and Values**
```css
line-height: value;
```

##### Common Values:
- **Normal**: Default spacing based on the browser’s calculation.
- **Number**: Multiplier of the font size (e.g., `1.5` means 1.5 times the font size).
- **Length**: Specifies spacing in fixed units (e.g., `20px`).
- **Percentage**: Based on the font size (e.g., `150%`).


### **2. Letter Spacing**

#### **What is Letter Spacing?**
- The `letter-spacing` property adjusts the horizontal spacing between characters in text.

#### **Why Use Letter Spacing?**
- To improve text readability.
- To achieve a specific design aesthetic.

#### **Syntax and Values**
```css
letter-spacing: value;
```

##### Common Values:
- **Normal**: Default spacing.
- **Length**: Fixed spacing in units (e.g., `2px`, `0.1em`).
