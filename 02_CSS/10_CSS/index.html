## 1. Pseudo Classes

### What is a Pseudo Class? A pseudo-class is a keyword added to a selector that specifies a special state of the selected elements. Pseudo-classes allow you to apply styles based on user interactions, element positions, or states without modifying the HTML structure. ### Why Use Pseudo-Classes? - They enhance user experience by providing dynamic styling. - They allow styling based on element state without requiring JavaScript. - They improve readability and maintainability of CSS code.
