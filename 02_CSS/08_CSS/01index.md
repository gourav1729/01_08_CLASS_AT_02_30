### **1. Introduction to CSS Units**

#### **Absolute Units**
- Fixed and do not depend on the parent or root element.
- Common examples: `px`, `cm`, `mm`, `in`.

#### **Relative Units**
- Flexible and adapt based on the parent or root element.
- Common examples: `%`, `em`, `rem`, `vw`, `vh`.

### **2. Pixel (`px`) Unit**

#### **What is a Pixel?**
- A pixel (`px`) is an absolute unit representing a single dot on the screen.
- It provides precise control over dimensions, making it ideal for fixed layouts.

#### **Advantages of Pixels**
- Consistent sizing across devices.
- Ideal for designs requiring exact measurements (e.g., buttons, images).

### **3. Relative Units Overview**

#### **Percentage (`%`)**
- Defines size relative to the parent element.

#### **em**
- Relative to the font size of the parent element.

#### **rem**
- Relative to the font size of the root element.
